# Citrusi — Mixed Citrus

Final renamed branding based on the selected mixed-citrus preview. The artwork
retains the purple pixel cartridge, overlapping lemon and orange slices, small
green leaf accent, and dark retro palette. The banner replaces the legacy
branding with a `CITRUSI` wordmark and `CITRUS INSTALLER` tagline.

- `icon.png` — 48 × 48 RGB application icon
- `banner.png` — 256 × 128 RGBA application banner with transparency

The selected files are also installed at the production artwork targets:

- `icon.png`
- `cia/banner.png`
- `ctr-template/icon.png`
- `ctr-template/banner.png`
