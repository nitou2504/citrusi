# Citrusi logo concepts

Four restrained, citrus-themed directions for the 3DS/homebrew identity. Each
concept includes a 256×128 banner and a matching 48×48 icon so it can be
previewed at both the CIA banner and HOME icon sizes.

| Concept | Banner | Icon | Direction |
| --- | --- | --- | --- |
| **01 · Citrus Slice** | `01-slice-banner.png` | `01-slice-icon.png` | A bright orange slice with a small leaf: the clearest, most immediately readable mark. |
| **02 · Pocket Citrus** | `02-pocket-banner.png` | `02-pocket-icon.png` | A tiny handheld silhouette with a citrus-colored screen; playful and explicitly portable. |
| **03 · Citrus Circuit** | `03-circuit-banner.png` | `03-circuit-icon.png` | A segmented lime crossed with simple PCB traces; the most maker/homebrew-oriented option. |
| **04 · Grove Badge** | `04-grove-banner.png` | `04-grove-icon.png` | A compact citrus grove with sun, fruit, and trunk; the warmest and friendliest direction. |

All concepts retain the existing visual language: dark navy `#1e2d50`
background, inset light-blue pixel border, small hard-edged shapes, and a
limited citrus palette with a restrained purple accent. The PNGs are RGB and
were made locally with Pillow; no project code or dependencies are changed.
